# Where `x2_assets import` puts each client file inside client_data (docs/tools/client-data.md#layout).
#
#   <folder>  <name pattern>  [<archive pattern>]
#
# First match wins; patterns are case-insensitive globs (`*`, `?`, `[0-9]`); `{archive}` in a folder is the source
# archive without `.kom`. Anything no rule matches goes to _unsorted/{archive}. A living layout: refine it as needs
# show up.
# The layout never changes what pack writes (the manifest is keyed by name), so moving rules or files is always safe.
